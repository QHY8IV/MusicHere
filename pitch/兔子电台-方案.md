# 《兔子电台》作品方案

> 马拉松里的配速兔，现在在你的耳机里。
> 赛道：创新音乐产品（落地形态：QQ 音乐播放器里的「跑步电台」）
> 演示：`http://121.40.217.6/`（电脑上点「看兔子带跑 · 75 秒」即可，不需要麦克风 / 定位 / 注册 / HTTPS）

## 一句话

步频掉了，音乐先快一点点，把你带回去；回来了，再踩着拍子陪你跑；收工时节拍渐慢、音量淡出，给你一张成绩单。

## 一、那个瞬间

> 跑到第 5 公里，腿开始沉。你没发现，但步频已经从 168 掉到了 162，配速跟着慢了下来。
> 马拉松里有配速兔：一个人举着牌子在前面，你只要跟着他。可平时一个人跑，没有兔子。

- **用户**：有目标的业余跑者（跑步是听歌最多的运动场景之一，戴耳机跑的人本来就多）。
- **难受的瞬间**：不是「想听什么歌」，而是「我在不知不觉地慢下来」。现有的跑步歌单只挑和你同速的歌，对你掉速这件事毫无反应。
- **兔子的做法**：不唠叨。你在目标附近时，音乐只是锁在你的脚步上；步频掉到目标以下 4 步并持续 2 秒（说明是真的累了，不是抬了一下脚），音乐才先快一点点（最多 3%，不锁相位），你会不自觉地跟着快一点；回到目标附近稳住 2 秒，再锁回你的脚步。

## 二、一次跑的完整流程（一条主线）

| 阶段 | 音乐在做什么 | 设计 |
| --- | --- | --- |
| 热身 | 跟随：锁在你的脚步上 | 先不催你 |
| 带跑 | 陪跑 → 掉速时领先 3% → 回来后锁回 | 只在需要的时候出手 |
| 冷却 | 节拍从当前步频一路降到 120，音量同步淡出，自动收尾 | 不让你听完又去摸手机 |
| 成绩单 | 平均步频、掉速 → 被带回、平均回来用时、步频 / 兔子曲线（一张可保存的 PNG） | 一次跑的结局 |

## 三、AI 在这里做什么

不是「把标签换成歌单」，而是**实时感知 + 闭环控制**，全部在手机浏览器里本地运行：

1. **感知**：加速度计 → 起音强度 → 按时间戳重采样到均匀网格（手机传感器采样间隔并不均匀）→ 自相关估计步频，并用「梳子」估计每一步的相位。
2. **决策**：带迟滞的状态机判断「掉速 / 被带回」（避免在阈值上抖动），决定音乐是锁定、领先还是冷却。
3. **生成**：实时合成的原创曲（速度和调可无损变化），逐拍锁相到你的脚步。
4. **反馈**：每一步落地是否踩在拍子上（合拍率）、掉了几次、多久回来。

大模型目前不在主线上：兔子电台的价值在「实时、本地、毫秒级」，这恰恰不是大模型擅长的部分。（后续可让大模型写冷却后的一句话总结或选歌理由，非必需。）

## 四、落地到 QQ 音乐

- **资产**：曲库里的每首歌离线算好 BPM 和节拍网格；播放时在 ±10–15% 内实时变速即可，不需要分轨。超出范围就改为按步频选下一首（`pickSongForCadence`，已实现）。
- **场景**：跑步是播放器里已经存在的高频场景，兔子电台是它的一个模式，不是新 App。
- **指标（要用 QQ 音乐的真实数据验证，我这里没有）**：跑步场景人均时长、完整收听率、冷却段留存、成绩单分享率。
- **版权**：实时变速属于播放器能力；成绩单只导出步频曲线，不导出音频。

## 五、诚实的限制

1. **演示用的是「模拟跑者」**：一个我写的模型（体力在两个时间窗里下滑；跑者会不自觉地向音乐的速度靠拢，强度是我设的参数）。它的脚步走的是和真实加速度计**同一条检测管线**，所以能证明「机制是通的」：掉速被检测到 → 兔子领先 → 步频被拉回 → 锁回脚步 → 冷却。**它证明不了真实跑者一定会被带回来**，那需要真人实测。界面和成绩单上都标着「模拟跑者（模型）」。
2. **真跑只有代码路径，没在真机上验证**：手机佩戴位置（臂包 / 口袋 / 手持）、真实步态的信号形状、iOS 的「动作与方向」权限都需要实测调参。
3. **曲库是 5 首实时合成的原创曲**，没有接 QQ 音乐曲库。
4. **原生 App 未做**，目前是网页版（手机浏览器可用）。
5. 没有 HTTPS：不影响兔子电台（只用加速度计），但手机浏览器在非 HTTPS 页面里可能不开放加速度计权限，真跑建议上 HTTPS。

## 六、对照评审偏好（见 [获奖作品分析.md](获奖作品分析.md)）

| 规律 | 兔子电台 |
| --- | --- |
| 具体的人 + 具体的难受瞬间 | 有目标的业余跑者；第 5 公里不知不觉掉速 |
| 一句话能复述的名字 / 隐喻 | 配速兔 |
| AI 做的不是推荐 | 实时感知 + 闭环控制 + 生成 |
| 绑定 QQ 音乐资产与指标 | 曲库 BPM / 节拍网格；跑步场景时长与留存 |
| 有设计过的结局 | 冷却淡出 + 自动收尾 + 成绩单 |
| 克制 | 一条主线：热身 → 带跑 → 冷却 → 成绩单 |
| 能当场体验 | 电脑上 75 秒看完一次完整的跑，不需要任何权限 |

## 七、评委 75 秒体验路径

1. 打开链接，点「看兔子带跑 · 75 秒」。
2. 热身：音乐跟着步频，几秒内数准。
3. 带跑：看实时曲线；约第 28 秒步频掉到 162–163，横幅变红，「兔子领先 3%」，音乐速度（紫线）高于步频（绿线），约 10 秒后回到 168。
4. 约第 51 秒第二次掉速，同样被带回。
5. 约第 64 秒进入冷却，节拍一路降到 120，音量淡出；自动出成绩单，可保存为图片。
6. 想看同一个引擎的另一面：页面底部「街头共鸣」。
