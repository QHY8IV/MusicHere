## 3. 我归纳的 7 条规律

1. **一个具体的人 + 一个具体的难受时刻。** 钢琴老师备课、舞者一边放歌一边录像、散场后的失落、失眠夜没力气选歌。不是「通勤」「跑步」这种泛场景。
2. **一个能一句话复述的名字 / 隐喻。** 失物招领处、日落电台、花语黑胶、看 MV 电台。评委记住的是名字，再去看机制。
3. **AI 做的是「生成 / 感知 / 决策」，不是把标签换成歌单。** 扩散模型出伴奏、多模态融合、带规则校验的 Agent、对话生成黑胶。连只用 AI 写代码的《练舞助手》也拿了奖，评语夸的是「体验打磨」——说明**AI 是不是核心不如问题选得准重要**。
4. **绑定 QQ 音乐已有的资产和指标。** MV / 歌词 / 分段、演出流量、横屏播放器 DAU；成果落在「下一次播放 / 时长 / 付费 / 留存」上。
5. **有设计过的结局。** 末尾自动静音、归途电台把人送回现实、从拍照识谱到伴奏的完整链路。
6. **克制。** 评语用「克制」「有章法」「技术路径清晰」「定义精准」；获奖作品都是**一条主流程**，不是功能列表。
7. **能当场体验。** 获奖作品几乎都挂了可打开的 Demo（pages.dev / vercel / netlify）、演示视频或线上平台。但这只是入场券：《一首歌，去远方》有 Demo 也没获奖（我的推断：「歌 → 旅行目的地」离音乐消费闭环较远）。

## 4. 「共鸣」对照

| 规律 | 共鸣原来 | 评价 |
| --- | --- | --- |
| 1 具体的人 / 时刻 | 通勤 / 散步 / 跑步 | △ 泛。最强的瞬间其实是「脚步和鼓点总是错开」 |
| 2 名字 / 隐喻 | 「耳机的第三种模式」「让世界为你的歌伴奏」 | ✓ 已经很强 |
| 3 AI 的作用 | 核心是实时 DSP + 生成式合成；LLM 只在入景 / 推荐 / 出题，且真实模型未联调 | △ 技术深，但在「AI Hackathon」里 AI 叙事偏弱 |
| 4 QQ 音乐资产 | 5 首合成原创曲，没接曲库；方案里有可行性论述 | ✗ |
| 5 结局 / 闭环 | 共鸣片段可保存分享、共鸣指纹 | △ |
| 6 克制 | 3 种模式 + 地点层 8 个功能 + 猜歌 + 漂流瓶 + 明信片 | ✗ 最大的问题：评委 1–2 分钟内抓不到主线 |
| 7 能当场体验 | **HTTP 演示站上核心功能根本不能用**（见下） | ✗✗ |

### 最致命的一条（已修复）

演示站是纯 HTTP（`http://121.40.217.6/`）。浏览器在非安全上下文里：
- 不提供**麦克风**；
- 也不提供 **`AudioWorklet`**——共鸣的整条分析链路（起音检测）都依赖它。

也就是说，评委打开链接、点「开始共鸣」，只会看到歌自己在放，「对拍 / 定调」一个都不会发生；就算他们在街上，也一样。**产品最强的一击在评委面前是死的。**

## 5. 这次做的改动

| 改动 | 为什么 |
| --- | --- |
| **模拟街头**（`app/src/lib/resonance/demo-street.ts`、`listener.startDemo`） | 用一段合成的脚步 / 手鼓 + 嗡鸣当「世界」，同时喂给分析、小声放出来。不要麦克风、不要定位、不要站在街上。两个场景：江边散步（112 BPM · A）/ 街头艺人（96 BPM · G），切换时能看到引擎约 5 秒重新跟上 |
| **`ScriptProcessor` 兜底** | HTTP 下没有 `AudioWorklet` 时，用同一套算法退回 `ScriptProcessor`，分析链路在任何页面都能跑 |
| **麦克风失败自动降级** | 没权限 / 非 HTTPS 时不再「静默失败」，而是自动切到模拟街头，并说明原因 |
| **一键 A/B：「听听没有共鸣的样子」** | 共鸣是「对比」才有感觉的东西：一键关掉对拍 + 定调，再一键打开 |
| **欢迎页只讲一件事** | 主按钮「30 秒听见共鸣」→ 自动登录 → 直达共鸣页并自动开始；其余功能降为次要入口 |
| 单测 | 模拟街头：整数拍、首尾无缝、峰值不削波、被引擎自己的节奏估计认出（96 / 112 BPM）、可复现 |

实测（线上 HTTP 站、真实浏览器、无麦克风权限）：点击后约 3 秒锁定 112 BPM，相位差 2–14 ms → 2–6 ms，歌从 F 大调移到 D 大调（A 为属音）；切到街头艺人后约 5 秒重新锁定 96 BPM、G 大调；A/B 切换后回到「自由播放 · F 大调」，再打开又重新锁定。

## 6. 还没做 / 需要你来决定

1. **HTTPS**：让「真实麦克风」也能用。需要在阿里云安全组放行入方向 TCP 443，之后可用 Caddy + `121-40-217-6.sslip.io`（国内服务器未备案域名可能被运营商拦截，需要实测）。
2. **收窄叙事**（改文案，不改代码）：路演 / 投稿只讲「街头共鸣」这一条主线——痛点（脚步和鼓点总是错开）→ 现场 A/B → 一张共鸣片段。跑步、声景、地点层降为「同一个引擎的延伸」，各一句话。
3. **AI 叙事**：接入真实大模型后（`AI_API_KEY`），把「入景」做成可见的主流程；或者明说：这个作品的 AI 是「实时音频理解」，大模型只负责读懂画面。
4. **QQ 音乐资产**：没有曲库授权就不能真接。可以把方案里已有的「离线节拍网格 + 实时变速变调」做成一张图，并用 QQ 音乐自己的指标（例如横屏播放器 DAU、人均时长）论证落地，而不是靠合成曲。
5. **真机实测**：蓝牙耳机延迟、真实街道噪声、手机佩戴位置——现在全是合成数据验证的。
